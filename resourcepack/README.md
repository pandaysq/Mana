# Mana resourcepack

Плагин ожидает шрифт `core:mana` и три белые PNG-текстуры:

- `assets/core/font/mana_star.png` — звёздочка;
- `assets/core/font/mana_frame.png` — один сегмент рамки;
- `assets/core/font/mana_cursor.png` — бегунок.

Текстуры намеренно не включены: их рисует автор ресурс-пака. Рекомендуемый
размер — 8 px по высоте, ширину можно менять вместе с `hud.width-steps`.
Цвет накладывается компонентом текста, поэтому PNG должны быть белыми с
прозрачным фоном.

`hud.ascent` задаёт вертикальное положение bitmap-провайдера. В JSON он сейчас
равен 8; если полоска выше панели еды, уменьшайте ascent, если ниже —
увеличивайте. `hud.shift-x` и `hud.width-steps` находятся в config.yml:
подберите shift-x для горизонтального выравнивания, а width-steps — для
длины полоски. Для проверки отправляйте себе ресурс-пак и меняйте значения
через `/mana reload`.

Для Paper 1.21.11 используется `pack_format: 75`.
